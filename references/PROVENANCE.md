# Project provenance

Catalytic-Magic-Memory is the canonical home of the reusable magic-factory project. Catalytic-Magic-Cost is a historical development of the same scientific family. Its useful refinements and finite checks are incorporated into the scientific account and the single verification command.

The preserved records are independent of the original repository's continued availability:

- [Exact source snapshot](https://github.com/GoGoKo699/Catalytic-Magic-Memory/tree/32222d9143ea8b796b5143ac038afb90effd85bb): all 17 original files, with their paths and bytes unchanged.
- [Complete Git history and restoration instructions](https://github.com/GoGoKo699/Catalytic-Magic-Memory/blob/3f9ec08e2d08c18d7ef35b665080a8143a5d45fa/README.md): original commits, branches, tag and PR heads, captured public metadata, integrity checks and coverage limits.
- [Scientific integration map](https://github.com/GoGoKo699/Catalytic-Magic-Memory/blob/3f9ec08e2d08c18d7ef35b665080a8143a5d45fa/MIGRATION.md): every source file and its role in the current account or archive.

These archives record development history. Use the [scientific route](../science/README.md) and [related-work account](related-work.md) for current statements, assumptions and external attribution.
